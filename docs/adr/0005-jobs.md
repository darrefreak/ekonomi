# ADR-0005: Background Jobs

## Status

Accepted (Phase 0)

## Context

Normalisering, metrics, forecast, anomalies, vehicle TCO m.m. ska köras asynkront. Jobs får inte skapa dubbletter eller läcka över hushåll.

## Decision

- BullMQ + Redis.
- Varje job: `householdId`, `jobType`, `idempotencyKey`, `payloadVersion` / `calculationVersion` där relevant.
- Jobs är idempotenta och säkra att köra om.
- Worker-process separat (`worker` service i Docker).
- Job types listade i ARCHITECTURE (IMPORT_SOURCE … MONITOR_LEASE_MILEAGE).
- V1: de flesta körs mot mockdata / no-op med spårbar status.

## Consequences

- API enqueue:ar; worker exekverar; UI visar job/import status.
- Metrics precompute via CALCULATE_METRICS / CALCULATE_NET_WORTH.
- Observability: job IDs i structured logs.

## Alternatives considered

- Synkron beräkning i varje request — rejected for dashboard performance.
- Cron-only without queue — rejected (poor retries/idempotency).
